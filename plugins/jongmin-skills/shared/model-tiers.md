# 모델 티어 — 유일한 바인딩 지점

전 스킬은 모델을 T1/T2/CX 티어명으로만 참조한다. 모델 ID·별칭을 개별 스킬에 박지 않는다.
**허용된 예외 1곳**: 에이전트 정의 frontmatter(`agents/*.md`)는 별칭을 직접 쓸 수밖에 없는
구현 지점이다 — 현재 `agents/lane-reviewer.md`의 `model: opus`가 T2 바인딩 구현이며,
세대 교체 시 이 파일과 그 줄을 **함께** 수정한다.

| 티어 | 역할 | 바인딩 | 지정 방법 |
|---|---|---|---|
| T1 | 지휘·착지 검증·최종 판정 | 세션 모델 (현재 최상위) | 서브에이전트/스킬에 `model` 필드 **생략** (inherit) |
| T2 | 실행(쓰기 레인)·독립 리뷰 | `opus` 별칭 | `model: opus` |
| CX | 명세 생성·대안 제시·반박 자문 | codex CLI 기본값 | `-m`/`--model` **지정 금지**, `~/.codex/config.toml` 기본값 (일일 자동 업데이트 환경 전제) |

발진 API에서 `model` 생략은 T1 상속이다 — T2 레인 발진 호출은 모델을 **명시**하고, 착지
보고에 실행 모델 식별자를 기재한다 (실측: 8레인 전건 바인딩 미확인 — 표만으로는 강제되지 않는다).

## 승격 밸브

구현 난이도가 판정 난이도보다 높으면 쓰기 레인을 T1로 승격할 수 있다. 조건:

1. T2 실패 후 **프롬프트 개선 → 1회 재시도**가 선행되어야 한다 (능력 한계 vs 프롬프트 품질
   구분). 실패 정책 "접근 3회"와의 회계: 재시도 1회는 3회에 포함되고, 승격은 남은 시도를 T1이 잇는다
2. 승격 사유와 재시도 이력을 장부에 기록
3. T1 상시 실행자화 금지 — 승격은 웨이브 단위 예외다

## 교차 리뷰 비대칭 규칙

근거: arxiv 2607.21656 (Claude→Codex 리뷰는 개선, 역방향은 악화. 프리프린트 1편이므로 금지가 아닌 가중치 조정).

- CX는 **최종 리뷰어가 아니라 자문**이다: 명세 초안·대안 접근·가설 반박에 강점 배치
- CX 리뷰 소견은 자동 반영 금지. T2 리뷰와 갈리면 **T1이 실측(재현·계측)으로 판정**한다
- 매장 방지: CX 지적은 **반증 방법 없이 기각 금지**
- CX가 생성한 명세·대안은 T1/T2가 리뷰한다 (연구가 지지하는 방향)
- **필수 CX 검증은 각 스킬이 정한 큰 단위 산출 경계에서 발진한다** — 대표 경계는 계획 확정·
  착지 범위·**측정 판독 확정**·완료 선언·스킬 릴리스. 반복·커밋별 투입 여부와 반박 축은 위험도와
  해당 스킬의 접합 규칙이 정한다(conductor는 상시 2슬롯, loop는 트리거 기반). 스냅샷·독립성이
  유지되면 병렬·선행 가능. **접합 큐 포화는 면제가 아니라 발진 유예**다 — 생략한 게이트는
  장부 실행 메타에 사유·대체 통제와 함께 기록한다

## CX 재현성

CX 모델은 자동 업데이트로 바뀌므로 실행마다 실제 모델 식별자를 장부에 기록한다.
회수: `grep '^model' ~/.codex/config.toml` + `codex --version` (이벤트 JSONL에는 모델 필드가 없음 — 실측 확인).
