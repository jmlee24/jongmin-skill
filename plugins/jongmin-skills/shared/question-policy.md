# 질문 정책 — 발진 배치 · 런 중 무질문 · 종료 배치

원칙: 질문은 정보 수집이 아니라 **실행 결과를 바꾸는 결정 인터페이스**다.
즉문즉답은 사용자의 제어권을 계속 빼앗는다 — 뭉텅이로 묻는다.
질문 수보다 **질문 비용의 예측 가능성**이 사용자 체감을 결정한다.

## 발진 배치 (스킬 시작 시 1회)

- AskUserQuestion **1콜, 최대 4문항**. 실행 결과를 바꾸는 결정만:
  범위 경계 / 파괴·불가역 권한 / 더티 트리·커밋 권한 / 성공 기준
- 취향·스타일·나중에 바꿀 수 있는 선택은 질문 금지 — 보수 기본값 + 장부 기록
- **질문에 담는 전제·수치는 저장소로 확인한 뒤 묻는다** — 사용자가 기억하는 값과 다를 수
  있으면 그 차이를 질문에 미리 적는다 (실측: 이름이 비슷한 큐 2개를 구분 없이 물어 반문 유발)
- 무질문 스킬(loop·sortie)은 발진 인자가 이 배치를 대체한다 — 인자에 없으면 보수 기본값

## 런 중 (질문 금지)

빠뜨린 질문·새 판단 지점은 즉시 묻지 않고 **유예 3분류**로 장부에 기록한다
(기록 형식 4요소는 장부 규격 2절 — 분류가 다르면 대응이 다르다):

- `defer` — 답 없어도 보수 기본값으로 전진 (4요소 기록)
- `gate` — 해당 갈래만 보류, 다른 작업 전진
- `block` — 금지선·불가역·완료 조건 붕괴 → 중단·보고 (loop는 `exit_signal:"blocked"`).
  단, 금지선 충돌이라도 **해당 갈래만 보류하면 다른 작업이 전진 가능한 경우는 `gate`**다 —
  작업 전체가 금지선 없이 성립 불가할 때만 block (sortie의 갈래 보류 규칙과 동일 경계)

즉시 질문 예외 (질문 가능 스킬 한정 — loop·sortie는 도구 차단이라 해당 없음):
불가역 작업 / 명시 금지선 충돌 / 사용자 기존 변경 덮어쓰기 위험 / 3접근 소진.

## 종료 배치 (보고 시 1회)

유예 결정을 **배치 1세트**로 제시한다 — "지금 답해야 전진 가능한 것"과
"나중에 바꿔도 되는 것"을 분리. 항목별 즉문즉답 금지.
권장을 붙이면 **어떤 사실이 나오면 그 권장이 틀리는지**(반증 조건)를 한 줄로 함께 적는다
(실측: 반증 조건 없는 권장 3건 중 2건이 사용자 판단으로 뒤집힘).
